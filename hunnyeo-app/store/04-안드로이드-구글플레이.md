# 안드로이드(Google Play) 등록 가이드

iOS용 `01`~`03` 문서와 콘텐츠는 똑같이 씁니다. 여기는 **구글플레이에서만
다른 부분**만 모았습니다. Capacitor 프로젝트엔 이미 `android` 설정이
들어있으니(`capacitor.config.ts`), 아래 순서대로 하면 됩니다.

---

## 1) 네이티브 안드로이드 프로젝트 만들기

로컬(맥/윈도우 컴퓨터)에서, `hunnyeo-app` 폴더 안에서:

```bash
npm run build
npx cap add android   # 처음 한 번만 — android/ 폴더가 생깁니다
npx cap sync android
npx cap open android  # Android Studio 가 열립니다
```

## 2) AdMob 앱 ID 넣기 (광고가 있으니 필수)

`android/app/src/main/res/values/strings.xml` 에 추가:

```xml
<string name="admob_app_id">ca-app-pub-3940256099942544~3347511713</string>
```

> 이건 구글 공식 **테스트** 앱 ID입니다. AdMob 콘솔에서 본인 앱을 등록하면
> 실제 앱 ID가 나옵니다 — 그걸로 교체하세요. `lib/hunnyeoAds.ts` 상단 주석에
> 같은 값이 iOS용과 같이 적혀 있으니 거기서 안드로이드용만 바꾸면 됩니다.

`android/app/src/main/AndroidManifest.xml` 의 `<application>` 태그 안에 추가:

```xml
<meta-data
  android:name="com.google.android.gms.ads.APPLICATION_ID"
  android:value="@string/admob_app_id"/>
```

## 3) 서명(Signing) — Play App Signing

- Android Studio → Build → Generate Signed Bundle/APK → **Android App Bundle(.aab)** 선택
- 새 키스토어(keystore) 만들기 — **이 파일과 비밀번호를 꼭 백업하세요.**
  분실하면 같은 앱으로 업데이트를 올릴 수 없습니다 (구글 Play App Signing에
  등록해두면 키 분실 시에도 구글이 도와줄 수 있으니, 업로드 시 "Play App Signing 사용"을 꼭 체크)

## 4) Google Play Console 계정

- 가입비 **$25 (최초 1회, 평생)** — 애플과 달리 연회비 없음
- 신규 계정은 구글 정책상 **비공개(closed) 테스트를 12명 이상에게 14일 이상**
  진행해야 전체 공개(production) 전환이 열립니다. 가족/지인 계정으로 테스트
  트랙에 참여시키는 게 가장 빠릅니다.

## 5) Data safety 설문 (앱 정보 보호 — iOS 설문과 똑같은 답)

`02-개인정보-답안.md` 표를 그대로 옮기면 됩니다.

| Google 설문 항목 | 답 |
|---|---|
| 데이터 수집함? | 예 |
| 이메일 주소 — 수집/공유 | 수집함 (로그인 시) · 제3자 공유 안 함 · 용도: 앱 기능 |
| 기기/기타 ID — 수집 | 수집함 (AdMob 광고용) · 용도: 광고 |
| 수집 데이터 암호화 전송 | 예 (HTTPS) |
| 삭제 요청 가능 | 예 — 앱 내 "기록 초기화" + 문의 메일 |

## 6) 콘텐츠 등급 설문 (Content rating)

IARC 설문에서:
- 폭력·성적 콘텐츠: 없음
- 공포/긴장 요소: **약간 있음** (글자스킬 챕터의 귀신 관련 속설) → iOS 12+ 와
  비슷하게 **12세(Teen)** 정도로 나올 가능성이 높습니다. 설문에 그대로
  정직하게 답하면 자동으로 등급이 산정됩니다.

## 7) 광고 선언 (매우 중요 — 빠뜨리면 리젝)

Play Console → 앱 콘텐츠 → **광고** 섹션에서
**"예, 내 앱에 광고가 포함되어 있습니다"** 로 답해야 합니다.
(iOS 와 달리 안드로이드는 이 질문에 "아니오"로 잘못 답하면 바로 정책 위반 처리됩니다)

## 8) "광고 제거" 인앱 상품 만들기

Play Console → 수익 창출 → **제품 → 인앱 상품** → 상품 만들기

| 항목 | 값 |
|---|---|
| 제품 ID | `remove_ads` ← **iOS와 똑같이, 코드(`lib/hunnyeoPurchase.ts`)와 정확히 일치해야 함** |
| 이름 | 광고 제거 |
| 설명 | 화면 아래 배너 광고를 영구히 없앱니다 |
| 가격 | 990원에 가장 가까운 등급 |

만들고 나서 **"활성화"** 로 전환해야 실제로 구매가 됩니다 (초안 상태로 두면 테스트도 안 됨).

## 9) 타겟 API 레벨

Google Play는 매년 "타겟 SDK 버전" 최소치를 올립니다. Capacitor 7 +
최신 Android Studio로 빌드하면 보통 자동으로 요건을 만족하지만, 업로드
시 Play Console 이 경고를 띄우면 `android/variables.gradle` 의
`compileSdkVersion` / `targetSdkVersion` 을 Play Console이 요구하는
최신 값으로 올리세요.

## 10) 등재 문구

`01-앱스토어-등재문구.md` 의 설명·키워드·스크린샷 요구사항은 그대로 재사용
가능합니다. 다만:
- **짧은 설명(80자)** 을 따로 하나 더 써야 합니다 — "밀가루팩부터 글자스킬까지, 2000년대 추억 뷰티 387개" 정도로 요약
- 아이콘은 512x512 PNG 한 장을 추가로 요구함 (앱 아이콘과 동일 디자인)

## 11) 제출 순서

1. 비공개 테스트 트랙에 AAB 업로드 → 테스터 12명 이상 모으기 → 14일 대기
2. Data safety / 콘텐츠 등급 / 광고 선언 / 개인정보처리방침 URL 입력
3. "프로덕션으로 승격(Promote to production)" → 심사 제출
4. 보통 며칠~1주 내 심사 완료 (애플보다 자동 심사 비중이 높음)
