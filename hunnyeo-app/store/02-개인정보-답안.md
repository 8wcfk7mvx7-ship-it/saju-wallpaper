# App Privacy 설문 답안 + 개인정보처리방침

## 1) App Store Connect "앱 개인정보 보호" 설문

첫 질문에 이렇게 답하면 끝납니다.

> **이 앱이 사용자로부터 데이터를 수집합니까?**
> → **아니요 (No, we do not collect data from this app)**

### 그렇게 답할 수 있는 근거

코드 기준으로 확인한 사실입니다. 심사에서 물으면 그대로 답하면 됩니다.

| 확인 항목 | 결과 |
|---|---|
| 서버 통신 | **없음.** `fetch` / XHR / WebSocket 호출이 코드에 0건 |
| 회원가입·로그인 | 없음 |
| 분석 도구(Analytics/Firebase/GA) | 없음 |
| 광고 SDK | 없음 |
| 위치·연락처·마이크·카메라 권한 | 없음 |
| 서드파티 SDK | Capacitor(코어/상태표시줄/스플래시/햅틱)뿐. 전부 기기 안에서만 동작 |

### 기기에만 남는 것 (수집이 아님)

아래는 사용자의 폰 안(localStorage)에만 저장되고 밖으로 나가지 않습니다.
애플 기준으로 **"수집(collect)"에 해당하지 않으므로** 설문에 신고하지 않습니다.

- 체크한 항목과 점수 (`hunnyeo_checked_v2`)
- 닉네임 (`hunnyeo_nickname_v1`)
- 프로필 사진 (`hunnyeo_avatar_v1`) — 앨범에서 고른 사진을 240px 로 줄여 저장
- 방명록 (`hunnyeo_guestbook_v1`) — 내 기기에만 보이는 메모
- 방문 기록, 최초 안내 확인 여부

> ⚠️ 프로필 사진은 사용자가 직접 고를 때만 접근합니다. iOS 는 시스템 사진 선택
> 화면을 쓰므로 사진 라이브러리 권한 설명문(NSPhotoLibraryUsageDescription)이
> 필요 없을 수 있지만, Xcode 에서 경고가 뜨면 아래 문구를 Info.plist 에 넣으세요.
>
> ```
> 프로필 사진으로 쓸 사진을 고를 때만 앨범을 엽니다. 고른 사진은 기기 안에만 저장되고 외부로 전송되지 않습니다.
> ```

### 훈녀생정 개인정보처리방침

**최종 수정일: 2026년 9월 9일**

#### 1. 수집하는 개인정보

훈녀생정은 **어떠한 개인정보도 수집하지 않습니다.**
회원가입이 없고, 서버로 데이터를 전송하지 않으며, 이용자를 식별하거나
추적하지 않습니다.

#### 2. 기기에 저장되는 정보

앱을 편하게 쓰기 위해 아래 정보가 **이용자의 기기 안에만** 저장됩니다.
이 정보는 외부로 전송되지 않으며, 개발자를 포함한 누구도 열람할 수 없습니다.

- 따라 한 항목의 체크 기록과 점수
- 이용자가 직접 입력한 닉네임
- 이용자가 직접 선택한 프로필 사진
- 이용자가 직접 작성한 방명록 내용
- 앱 사용 관련 설정값

앱을 삭제하면 위 정보는 기기에서 함께 삭제됩니다.
앱 안의 "기록 초기화" 기능으로도 언제든 지울 수 있습니다.

#### 3. 사진 접근

프로필 사진을 지정할 때만 시스템 사진 선택 화면이 열립니다.
선택한 사진은 정사각형으로 잘라 크기를 줄인 뒤 기기 안에만 저장되며,
외부로 전송되지 않습니다.

#### 4. 제3자 제공 및 위탁

수집하는 정보가 없으므로 제3자에게 제공하거나 처리를 위탁하지 않습니다.

#### 5. 광고 및 분석 도구

광고 SDK 와 분석 도구를 사용하지 않습니다. 이용자의 광고 식별자(IDFA)에
접근하지 않습니다.

#### 6. 아동의 개인정보

수집하는 정보가 없으므로 만 14세 미만 아동으로부터도 개인정보를 수집하지
않습니다.

#### 7. 콘텐츠에 관한 안내

앱에 담긴 내용은 2000년대에 유행하던 민간요법과 속설을 모은 추억 콘텐츠입니다.
과학적으로 검증된 정보가 아니며 의학적 조언을 대신하지 않습니다.
