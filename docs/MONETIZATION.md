# "오늘의 행운" 수익모델 & 시장 리서치 요약

> `/service/luck` 기능 기획 시 조사한 경쟁사 현황과 가격 정책 결정 근거를 정리한 문서입니다.
> 상세 원본 리서치는 세션 스크래치패드에 있으며, 이 문서는 실제 구현에 반영된 결론만 남깁니다.

## 경쟁 앱 현황 (국내 운세/사주 앱)

| 앱 | 특징 | 과금 방식 |
|---|---|---|
| 점신 | 누적 1,900만 유저, AI 기반 오늘의 운세 무료 제공 | 광고 + 리워드형 "행운패스"(광고 시청 시 일정 시간 광고 제거) |
| 헬로우봇 | 챗봇 캐릭터가 "복채"를 요구하는 세계관, 타로 콘텐츠 만족도 높음 | 프리미엄 IAP 중심 — 과도한 유료화로 이탈 후기 다수 |
| 포스텔러 | 사주·타로·주역 등 6,000건 이상 콘텐츠, 무료 비중 큼 | 콘텐츠 건당 800~1,100원 + 묶음 구매 시 약 30% 할인 |
| 기타 | — | 프리미엄 IAP $3.99~$7.99 (약 5,500~11,000원) |

## 결론: "코어 무료 + 광고" + "라이트 프리미엄" 하이브리드

1. **데일리 콘텐츠는 리텐션 도구다.** 매일 켜보는 습관이 핵심 가치이므로 결제 장벽을 두면 습관화(스트릭·알림)가 실패한다. 그래서 절기 개운법·용신 맞춤 팁·행운 컬러·매력 팁·메모·행운 기록까지 **오늘의 행운 기능 전체를 무료**로 열어둔다.
2. **광고로 기본 수익 확보.** 기존 `AdBanner`(카카오 애드핏 + 구글 애드센스)를 페이지 하단에 그대로 재사용한다. 별도 전면광고는 아직 넣지 않았다 — 데일리 습관 기능 초기에는 광고 피로도로 인한 이탈이 더 치명적이므로, 트래픽이 붙은 뒤 리워드형 광고("광고 보고 이번 절기 전체 캘린더 보기" 등)를 단계적으로 추가하는 것을 권장한다.
3. **기존 유료 리포트와의 퍼널 연결.** 이 앱은 이미 정통 사주 리포트를 유료로 판매 중이므로(`/service/charm`, `/service/hotcompat`, `/service/daewoon` 등 "프리미엄" 배지), 오늘의 행운은 비구매 사용자를 매일 앱에 붙잡아두는 무료 퍼널 역할을 하고, 개인화된 용신 팁에서 "더 깊은 사주 풀이가 궁금하다면" 형태로 자연스럽게 기존 유료 서비스로 연결하는 도입부 역할을 한다.
4. **향후 라이트 프리미엄 후보** (지금 버전엔 포함하지 않음 — 트래픽 확인 후 추가 권장):
   - 월간 절기 캘린더(다가올 절기 미리보기) — 990원~1,500원 단품 또는 광고 시청으로 해제
   - 광고 제거 + 심화 개인화(주간 리포트) 월 구독 3,900원~5,900원
   - 연간 구독 29,000원~39,000원 (월 환산 30~40% 할인)
